My journey v2 – “What I learned” comes first

The first tab is the most important one and opens by itself. Click the tabs, change the state, replay.

What changed in v2

  • 3 tabs, “What I learned” first and selected on arrival: 🧠 What I learned · 🗺️ My journey · 🪪 My ID. Same tab pattern as the room summary tabs (Prof comment 6).
  • The long list of stops moved to the 2nd tab; the stats moved to the 3rd. The page opens straight on the learning.
  • The celebration is now one slim line so the learning is on screen at once.

Inside “What I learned” (top to bottom)

  • 1 The big idea: the scenario’s teaches sentence, large, with Pip.
  • 2 My answer: the child’s own claim + because, the proof numbers as chips, and a 4-step “how sure” bar.
  • 3 Skills I practised: one card per stop: the skill name, “I learned …”, and “I showed it when …” with the child’s own words. Not-done stops are dashed.
  • 4 New words I know: only words he met (mean, median, mode, sample, prediction, evidence…), each with a one-line kid definition.
  • 5 Next time I can…: 3 small challenges (try a new question, a bigger class, ask a real class).

Build notes

  • Files: js/rooms/my-journey.js (new learnedNode(), tabs), css/my-journey.css. Uses buildJourney(); log and exports unchanged.
  • “I learned” lines: reuse learned from helpers/feedback.js (one per phase). The lines for Collect, Graph, Number, Chance, Conclude in this mock-up are examples; check them against the real file.
  • “New words” list: from a small content file (data/content/words.json), shown only for rooms the child finished. Ask Habiba to approve the definitions.
  • “I showed it when”: the child’s own text, textContent only. If empty, hide the line.
  • Tabs: role="tablist", arrow keys, first tab selected, ≥ 56px high. Print shows ALL panels, answers open.
  • Rewards stay about reasoning: no scores in this tab, no speed, no time.
