Open the live site (or Live Server over Wi-Fi: VS Code's Live Server shows a Network address; type it on the device).

## 1. Start page
- [ ] The page fits the screen with no sideways scrolling, in portrait and landscape.
- [ ] Tap the code box: the on-screen keyboard opens and doesn't hide the box.
- [ ] Typing a name (e.g. `Sara`) shows the warning; `owl-07` works and opens Question Studio.

## 2. Touch
- [ ] Every button can be hit first time with a finger (no "missed" taps).
- [ ] Buttons press down when tapped (the bouncy shadow).
- [ ] Nothing needs hovering (no hidden menus, no tooltips needed).
- [ ] Chosen answers show a ✓ as well as a colour.

## 3. Each room (one quick pass)
- [ ] **Question Studio:** pick a card, fix both questions, save a prediction. The step bar shows **Plan** on Task 3.
- [ ] **Data Hub:** Run survey. Answers pop in one by one and the tally grows. The "Let's draw a graph" button appears at the end.
- [ ] **Graph Lab:** all 4 chart buttons draw a chart. The numbers on the chart are readable at arm's length.
- [ ] **Number Lab:** Reveal → "Has the data changed your mind?" → Next. Wrong answers in Tasks 3–4 show a hint.
- [ ] **Chance Lab:** the unfair spinner picture shows a big red part. Run 500 finishes quickly (under 1 second).
- [ ] **Evidence Board:** finish the card. "📤 Save my work for my teacher" saves a file.

## 4. Saving the file (most important for the pilot)
- [ ] After "Save my work", where did the file go? (Chromebook: Files → Downloads; iPad: Files app or a "Download" prompt.) Write it here: ____________
- [ ] Can a child find and hand in that file the way your school does it (e.g. Google Classroom upload)? ____________
- [ ] Teacher view (start page → For teachers): import that file and you see the child's row.

## 5. Coming back and sharing
- [ ] Close the browser and open the site again: the code is still filled in on the start page.
- [ ] Teacher view → 🧹 Clear (tap twice): the code is gone and the next child starts fresh.

## 6. Settings
- [ ] Turn on "reduce motion" (Chromebook: Settings → Accessibility; iPad: Settings → Accessibility → Motion). Data Hub answers appear without animation.
- [ ] Zoom the page to 200% (Ctrl + plus): everything is still usable.
- [ ] Optional, screen reader (Chromebook: ChromeVox, Ctrl + Alt + Z; iPad: VoiceOver). Graph Lab's chart is read out as "Bar chart. 3 hours: 1 classmate…".
